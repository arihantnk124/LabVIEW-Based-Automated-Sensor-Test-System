# LabVIEW-Based Automated Sensor Test & Data Acquisition System

## Overview

This project demonstrates a Virtual Instrument (VI) developed using NI LabVIEW for real-time sensor monitoring, visualization, automated CSV data logging, and pass/fail validation.

The current implementation uses simulated sensor data and is designed so that it can later communicate with an ESP32 or Arduino over UART.

---

## Features

- Real-time sensor monitoring
- Live waveform visualization
- UART-ready architecture
- CSV data logging
- Pass/Fail validation
- Modular programming using SubVIs
