# Project Report

## Project Title
LabVIEW-Based Automated Sensor Test & Data Acquisition System

## Objective
To develop a Virtual Instrument (VI) in NI LabVIEW that monitors sensor values, displays them in real time, logs them to a CSV file, and validates sensor readings.

## Input
Simulated Temperature, Humidity, and Voltage values.

## Output
- Live monitoring
- Waveform graph
- CSV data logging
- PASS/FAIL indication

## Technologies
- NI LabVIEW
- UART (Planned)
- CSV
- Git
- GitHub
